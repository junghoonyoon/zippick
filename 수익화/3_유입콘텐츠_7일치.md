## 1일차 — 계산기형 (가장 안전하고 반응 좋음)

**제목**: 연봉 7천 · 현금 3억이면 지금 서울에서 뭘 살 수 있나 계산해봤습니다

```
요즘 대출 규제가 자꾸 바뀌어서 도대체 내가 얼마짜리를 살 수 있는지
헷갈리시는 분들 많을 것 같아 직접 계산해봤습니다.

조건: 무주택 · 생애최초 · 자기자금 3억 · 연봉 7천 · 금리 4.2% · 30년

- DSR 기준 대출 한도: 3.4억
- 규제지역 LTV 70% 기준 한도: 3.4억
- 취득세·중개보수 등 부대비용 3% 반영
→ 실제 매수 가능 상한: 약 6.2억

여기서 많이들 착각하는 게 "3억 + 대출 3.4억 = 6.4억까지 되겠네"인데
부대비용 빼면 6.2억이고, 규제지역은 주택가격 상한 6억 기준이 또 걸립니다.
6억 넘어가면 한도가 더 깎여요.

이 조건으로 노원구를 돌려보니 조건 통과 단지가 4곳 나왔습니다.
상계주공9는 최근 6개월 실거래가 +9.7%, 거래량도 늘었는데
필요 자기자금이 2.8억이라 딱 맞물리더라고요.

궁금하신 분들 댓글에 [지역 / 자기자금 / 연소득] 남겨주시면
매수 상한이랑 후보 한 곳 정도는 계산해서 답글 드릴게요.
오늘은 10분까지만 하겠습니다. 손으로 확인하느라 시간이 좀 걸려요.
```

> 실제 게시 전 `generate_report.py`를 돌려 **그날 기준 숫자로 갱신**하세요.
> 실거래는 매일 바뀝니다. 틀린 숫자 하나가 신뢰를 통째로 날립니다.

**제목**: "노도강 오른다"는 말 실거래로 확인해봤습니다

```
요즘 노도강 얘기가 많이 보여서 최근 6개월 실거래로 직접 확인해봤습니다.

노원구 상계동 기준
- 상계주공9(고층): +9.7% (거래 116건)
- 보람아파트: +14.2% (같은 구 대표 단지보다 4.5%p 더 오름)

오른 건 맞습니다. 그런데 두 가지가 걸립니다.

1. 두 단지 다 1988년 준공, 38년차입니다.
   정비사업 기대가 가격에 이미 들어가 있는 건지,
   실수요가 들어온 건지는 구분해서 봐야 합니다.

2. 같은 단지 안에서 거래가 편차가 32%입니다.
   "상계주공9 6억"이라는 말은 사실 의미가 없어요.
   동·층·향·수리 상태에 따라 4.9억도 있고 6.2억도 있습니다.
   평균만 보고 들어가면 비싸게 삽니다.

오른다/내린다 말싸움보다 본인 예산에서 뭐가 실제로 잡히는지가
훨씬 중요한 것 같습니다.

댓글에 [지역 / 자기자금 / 연소득] 남겨주시면 계산해서 답글 드릴게요.
```

부동산 앱에 나오는 "대출 가능 금액"이랑 은행이 실제로 내주는 돈은 다릅니다.

## 응대 스크립트

### ① 무료 요청 댓글이 달렸을 때 (건당 2분)

`수익화/주문/` 에 JSON을 만들고 `python3 generate_report.py` 실행 → 3줄만 옮겨 적기

```
[닉네임]님 조건으로 계산해봤습니다.

매수 가능 상한 약 6.2억 (DSR 3.4억 + 현금 3억, 부대비용 3% 반영 후)
노원구에서 조건 통과 단지 4곳 나왔고, 그중 상계주공9(고층)이
최근 6개월 +9.7%에 거래도 116건으로 활발합니다.
다만 1988년 준공이고 단지 내 가격 편차가 32%라 동·층을 꼭 보셔야 합니다.

나머지 후보 3곳이랑 계약 전 확인할 점까지는 댓글로 담기가 어려워서
정리한 리포트로 만들어두었습니다. 필요하시면 프로필 링크 참고해주세요.
```

**마지막 문장이 전부입니다.** 팔려고 하지 말고 "정리해뒀다"까지만 하세요.
더 밀면 광고가 되고 신뢰가 무너집니다.

### ④ "그래서 어디 사야 돼요?" — 반드시 이렇게 답하세요

```
그건 제가 정해드릴 수 없는 부분입니다.
저는 공개된 실거래 자료를 정리해서 판단 근거를 드리는 일까지만 하고 있어요.

데이터로는 [단지명]이 가격 흐름과 거래량이 제일 좋게 나왔습니다.
다만 38년 구축이라는 점, 자기자금이 0.2억 부족하다는 점이 걸립니다.

이 두 가지를 어떻게 보시느냐에 따라 답이 갈릴 것 같고,
그건 [이름]님 상황이 제일 정확하실 겁니다.
```

이 답변은 **법적으로 반드시 지켜야 하는 선**입니다.
특정 매물을 사라고 하고 그 거래에 관여하는 순간 무등록 중개가 됩니다.

```

바로 반영해서 다시 작성해드리겠습니다.

재작성으로도 해결이 안 되면 크몽으로 전액 환불 처리하겠습니다.
```

**1주일짜리 실험에서 환불 분쟁으로 시간을 쓰는 건 최악입니다.
말이 길어질 것 같으면 그냥 환불해주세요.** 리뷰 하나가 훨씬 비쌉니다.
