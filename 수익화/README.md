## 리포트 만드는 법 (건당 15초)

**1. 주문서 만들기** — `주문/A001_샘플.json`을 복사해서 값만 바꾸세요.

```json
{
  "주문번호": "A002",
  "고객명": "김OO",
  "보유주택": "no_home",
  "생애최초": true,
  "자기자금_억": 3,
  "연소득_만원": 7000,
  "월대출상환_만원": 0,
  "예상금리": 4.2,
  "대출기간": 30,
  "부대비용률": 3,
  "매수목적": "live",
  "검토지역": ["노원구", "남양주시"]
}
```

`보유주택` 값: `no_home` / `conditional_one_home` / `one_home_keep` / `multi_home`
`매수목적` 값: `live` (실거주) / `invest` (투자)

**2. 실행**

```bash
cd ~/Documents/집픽
python3 수익화/generate_report.py                        # 주문 폴더 전체
python3 수익화/generate_report.py 수익화/주문/A002_김OO.json   # 하나만
```

**3. 검수 (여기가 진짜 작업)**

`리포트/` 폴더의 HTML을 브라우저로 엽니다. **반드시 눈으로 확인하세요.**

- [ ] 후보가 0곳으로 나온 지역은 없는지 (있으면 고객에게 미리 알리기)
- [ ] 거래건수가 10건 미만인 단지는 없는지 (있으면 신뢰도 낮다고 코멘트 추가)
- [ ] 최근 실거래 날짜가 3개월 이상 지난 건 없는지
- [ ] 이상한 숫자나 깨진 문장이 없는지

**4. PDF 변환** — 브라우저에서 ⌘P → 대상을 `PDF로 저장`
→ 여백 `없음`, 배경 그래픽 `켬`

**5. 발송 후** — `주문/` 폴더의 JSON을 삭제하세요. 고객 소득·자산 정보입니다.
