## 유지하는 리포트

- 지도 → 도장과 종합 제목 → 가격·단지 조건 요약 → 종합점수·시장 신호 → 집픽 밴드와 상세 근거 순서.
- 도장은 매수 검토·우선 검토 초록, 매수 보류·다른 후보 우선 빨강, 조건부 검토 주황, 판단 보류 회색.
- 조건부 판정의 도장은 `조건부 검토`로 통일한다. 구체적인 이유는 큰 제목에서 설명한다.
- 큰 별점과 매수 판단 숫자는 상단에서 제외한다. 가격·단지 조건 별점, 종합점수·시장 신호와 상세 판단 기준은 보존한다.
- 같은 단지의 최근 거래 가격 판단은 집픽 밴드에서 설명한다. 상단 가격 요약은 다른 단지와의 평균 거래 가격 비교다.
- 재건축·리모델링은 각각의 단계 점수표를 쓴다. 공식 사업 종류·단계가 맞는지 함께 검사한다.
- 단지 고유값·주소·면적을 리포트까지 전달하고, 보고서가 준비되지 않은 후보는 열지 않는다.
- 분석 준비 실패 시 버튼을 비활성화하고 자료를 불러오지 못했다는 안내를 표시한다.

- 공식 통계의 기존·신축 용적률을 쓰는 조건과 기존 세대수 대조.
