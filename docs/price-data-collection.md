# 가격 비교에 필요한 실거래 자동 수집

리포트에서 단지와 선택 면적을 확인한 뒤, 가격 비교에 필요한 최근 60개월 실거래 원본을 확인한다. 단지의 행정구와 같은 기준으로 고른 1km 이내 인접 구의 비교 후보를 포함한다. 이미 정상인 월은 다시 수집하지 않는다. 정상 조회에서 거래가 없는 월도 완료된 월로 보관한다.

운영 서버가 빠졌거나 손상된 월만 국토교통부 API에서 받는다. 지역·월별 파일은 잠금과 임시 파일 교체를 사용하며, 모든 페이지와 거래 필드를 확인한 뒤 저장한다. 기존 정상 자료는 실패한 응답으로 덮어쓰지 않는다. 같은 지역·기간 요청은 합치고 수집 작업은 한 번에 하나씩 처리한다. 인증이나 호출 한도 오류가 나면 일괄 수집을 중단한다. 일시 오류는 정해진 횟수만 재시도한다.

`/api/apartment-price-source`는 `queued`, `collecting`, `ready`, `error` 상태와 자료 건수를 제공한다. 수집 중인 리포트는 계산을 기다리고, 완료 후 같은 단지·면적으로 가격 비교와 별점을 다시 계산한다. 실패하면 이유와 다시 불러오기 동작을 보여준다. 실제 거래나 평소 가격 차이를 계산할 근거가 없으면 별점을 만들지 않는다. 비교 조건을 넓히거나 면적을 환산한 결과는 기존 `자료 적음` 안내를 사용한다.

수집 기록은 운영 공용 폴더의 `price_data_collection_log.json`에 저장한다. 각 기록에는 지역 코드, 자료 종류, 처리 대상과 재사용·성공·실패·미처리 건수, 시작·종료 시각, 오류 코드만 담는다. 키, 예산, 개인 리포트는 저장하지 않는다. 다음 요청은 이미 저장된 월을 재사용하고 남은 월부터 처리한다. 정상 저장 시 원본 버전을 갱신해 가격 밴드와 시장·후보 점수의 이전 계산을 다시 사용하지 않는다.

로컬의 기본 replica 모드는 운영 공용 원본을 읽기 전용으로 동기화한다. 필요한 월이 없으면 운영 서비스에 수집을 요청하고, 운영 자료가 준비된 뒤 동기화를 마치고 계산한다. 원본 연결이 끊기면 마지막 정상 자료를 보존하고 연결 상태를 표시한다. `isolated` 모드는 테스트용이다.
