# 생활권 변화 공식 자료 확보 기록

**2026년 10월 12일 확인:** 성남 원도심 5개 신규 정비구역의 지정 사실과 이문4·휘경3의 진행 기록을 공식 사이트에서 확인해 시범 자료에 등록했다. 반경과 준공 예정일을 확인하지 못한 사업은 점수에 넣지 않는다.

원문과 사진은 복제하지 않고 필요한 사실, 확인일, 링크만 보관한다. 휘경3구역 정정은 `factCorrections`에 이유와 새 근거를 남겼다. SQLite의 이전 원본과 사업 이력은 삭제하지 않았다.

## 확보했으나 점수에 사용할 수 없는 자료

- [서울시 도시계획사업 현황 공간정보 OA-22712](https://data.seoul.go.kr/dataList/OA-22712/F/1/datasetView.do)는 2026년 9월 파일을 제공한다. 서울시는 **법적 효력이 없는 참고자료**라고 밝히며, 이용허락범위를 **공공누리 4유형(출처표시·상업적 이용금지·변경금지)**으로 표시한다. 이 작업에서는 기존 코드베이스의 2026년 2월 GeoJSON을 내부 대조에만 사용했다. 새 9월 파일을 상업 서비스용 점수 입력이나 재배포 파일로 가져오지 않았다. 구역 경계는 재사용 가능한 공식 원본과 이용 조건을 따로 확인해야 한다. 기존 지도에서 이 자료를 사용하는 범위도 별도 점검이 필요하다.
- [국토교통부 건축HUB 건축물대장정보 API](https://www.data.go.kr/data/15134735/openapi.do)는 사용승인일과 용도 등 건축물 속성을 제공한다. **2026-10-12 개발계정 활용신청이 자동 승인**되었고, 표제부 조회 기능 1개를 신청했다. 만료 예정일은 2028-10-12다. 키는 Git에서 제외된 로컬 `설정.txt`에만 두었다. 실제 API 조회로 산성동 385건, 이문동 3,457건, 휘경동 2,309건의 표제부를 `pipeline/cache/building_hub.sqlite3`에 출처·조회 시각과 함께 저장했다. 캐시와 문서에 인증키를 넣지 않았다. 단지 두 곳의 지번(산성동 1336, 이문동 149-8)은 현재 표제부 응답이 0건이었고, 휘경동 28-4는 1건이었다. 법정동 자료는 반경 1.5km와 일치하지 않으며 건축물 속성만으로 주거용 필지 경계 면적을 만들 수 없으므로 적법한 필지 도형도 필요하다.
- 검증된 법정동별 표제부 건수·조회일과 주거용 표제부의 연식 집계를 `data/building_hub_pilot_summary.json`에 내보냈다. 주거용은 주용도가 `단독주택` 또는 `공동주택`인 표제부 기록만 포함한다. 30년 이상 비율의 분모는 사용승인일이 유효하고 조회일보다 늦지 않은 주거용 기록 수다. 날짜가 없거나 잘못된 기록은 분모에서 제외하고 건수를 별도로 표시한다. `pipeline/export_building_hub_summary.py`를 다시 실행하면 저장된 전체 API 응답의 건수·지역 코드·출처를 확인한 뒤 이 파일을 갱신한다. 시범 단지의 분석 리포트 `생활권 변화`에서 이 자료를 **법정동 전체**로 표시한다. 한 표제부 기록은 한 세대·한 필지·한 건물과 같지 않다. 원본 건물 ID·주소·인증키는 리포트에 싣지 않으며, 반경 1.5km 건수나 미래 변화 점수 계산 입력으로 사용하지 않는다.
- 같은 날 포털의 **개인 일반 인증키를 재발급**했다. Git에서 제외된 `설정.txt`의 건축HUB·아파트 매매 실거래가 키를 함께 교체하고, 새 키로 건축HUB 표제부 1건 조회와 실거래가 API 정상 응답(`resultCode: 000`)을 확인했다. 기존 로컬 서버도 새 설정을 읽도록 재시작했다. 키 값은 이 문서와 저장소에 기록하지 않는다.

## 남은 자료

- [브이월드 연속지적도 2D 데이터 API](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=cadastral)는 필지번호(PNU)와 경계를 `LP_PA_CBND_BUBUN`으로 제공한다. 공식 안내상 한 번의 BOX/POLYGON 요청 범위는 2km² 이하여야 한다. **2026-10-12 개발키를 발급받아 Git에서 제외된 로컬 `설정.txt`에 저장했고, 2026-10-13 앱 설정에서 읽히는 것을 확인했다.** 키 값은 문서와 저장소에 기록하지 않는다. 개발키의 화면상 만료일은 2027-04-12다. 수집기와 전체 페이지 검증·SQLite 보관은 구현했으나 실제 필지는 아직 받지 않았다.
- [공공데이터포털 연속지적도 API 안내](https://www.data.go.kr/data/15056910/openapi.do)는 이용허락범위를 `제한 없음`으로 표기하지만, 연결되는 **브이월드 API의 키 발급 약관**은 제10조 ⑧에서 상업적 이용의 별도 허락, 제12조 ④에서 API 데이터 저장의 사전 승낙을 요구한다. 현재 집픽 서비스와 원본 저장을 모두 허용하는 승인 근거를 확인하지 못했다. 따라서 개발키가 있어도 필지 수집 명령은 두 허락의 확인 번호가 없으면 API를 호출하지 않는다. 포털의 데이터셋 표시가 브이월드 API 약관을 자동으로 대체한다고 판단하지 않는다.

1. 정비구역의 재사용 가능한 공식 경계, 단지 위치, 사업별 확정 완료 예정일. 현재 구역 주소만으로 1.5km 포함 여부를 단정하지 않는다.
2. 반경 안 노후 주거용 **필지 면적**과 확보한 건축HUB 사용승인일·용도를 잇는 공식 필지 경계·식별 자료. 건축물 연면적을 토지 면적으로 바꾸어 쓰지 않는다.
3. 새 보행 연결의 실제 경로와 개통일, 교통 이동시간, 새 시설의 운영일, 기존 가구수·흡수량·거래·임대 흐름, 공사 부담의 현장 근거.

위 입력이 모두 검증될 때까지 시범 단지의 미래변화점수는 `null`이다. 자료 부족은 0점이 아니다.

## 점수 칸을 채우기 위한 다음 수집 순서

1. [국토교통부 연속지적도](https://www.data.go.kr/data/15056910/openapi.do)의 필지 경계와 [GIS건물통합정보](https://www.data.go.kr/data/15123970/openapi.do)의 건물 위치·속성 제공 범위, 키, 이용 조건을 확인한다. 건축HUB 사용승인일·용도와 필지 식별값을 대조한다. 표제부의 대지면적을 건물마다 더하거나 법정동 전체를 단지 반경으로 간주하지 않는다.
2. 성남·동대문구의 공식 **정비구역 경계**와 단지 좌표를 겹쳐 반경 1.5km 안의 사업만 고른다. 발표문에 적힌 사업면적은 노후 주거용 토지와 실제로 겹치는 면적의 대체값이 아니다.
3. 각 사업의 최신 인허가 단계와 **공식 완료 예정일**을 확인한다. 날짜가 없는 사업은 5년 안에 준공된다고 계산하지 않는다. 이 상태에서도 확인된 사업 사실은 리포트에 표시한다.
4. 새 보행 연결·교통 이동시간·생활시설 운영일·입주 흡수량·공사 부담의 근거를 채운다. 지역 6개 항목과 단지 4개 항목을 모두 검증한 뒤에만 두 보조점수와 최종 점수를 공개한다.
