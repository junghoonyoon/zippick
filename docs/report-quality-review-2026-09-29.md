# 집픽 리포트 수정·검수 기록

## 바꾼 내용

- 가격 비교·거래 건수·거래 목록을 같은 전용면적의 개별 실거래에서 계산한다.
- 최근 3개월 5건 미만이면 6개월로 넓힌다. 그래도 5건 미만이거나 마지막 거래가 120일보다 오래되면 가격 판단을 보류한다.
- 비교 기준은 거래의 가운데 가격(중앙값)이다. 실제 거래 최저·최고 가격을 함께 보여주되 적정가나 미래 가격 범위라고 표현하지 않는다.
- 취소 표시 거래, 미래 날짜, 가격·면적이 없는 행은 제외한다. 높은 거래와 낮은 거래를 임의로 빼지 않는다.
- 첫 화면은 검토할 이유, 먼저 확인할 약점, 결정을 미룰 조건 순서로 읽는다. 추가 자기자금은 매수 판단 조건으로 쓰지 않는다.
- 점수가 높아도 주요 자료가 없거나 거래량이 감소하면 조건 확인이 필요한 결론으로 바꾼다.
- 거래가 이어졌다는 사실을 ‘쉽게 팔린다’로 표현하지 않는다. 출퇴근 시간은 추정값임을 함께 설명한다.
- 비교 단지는 현재 후보와 지역 내 별도 조회 결과를 함께 쓴다. 면적 차이 5㎡ 이내, 가운데 가격 차이 15% 이내, 유효한 최근 거래 표본을 확인한다.
- 카드의 6개월 평균도 같은 면적의 거래로 계산한다. 시장 신호는 별도 집계 범위와 기간을 표시한다.
- 거래 목록은 최신 3건을 먼저 보여주고 나머지를 펼칠 수 있다. 계산에 쓰인 모든 행을 확인할 수 있다.
- 공유 링크에는 실제 가격 분석에 쓴 면적을 포함한다.

## 실제 화면 확인

봉천동 두산에서 확인했다.

- 전용 114㎡대, 2026.04~2026.09 총 13건.
- 최근 3개월은 4건이므로 6개월로 확대.
- 가운데 가격 13억원, 낮은 거래 12.8억원, 높은 거래 13.5억원.
- 카드의 6개월 평균 13.13억원, 13건으로 일치. 평균과 가운데 가격은 정의가 달라 각각 표시.
- 거래 목록의 나머지 10건 펼치기 확인.
- 매물가 13.5억원 입력 시 가운데 가격보다 5,000만원 높다고 표시.
- 관악드림타운 전용 114㎡대가 비교 단지로 표시됨. 거래 기간과 건수를 각각 표시.
- 모바일 390×844와 데스크톱 1280×900에서 결론·가격·거래 목록의 줄바꿈과 정렬 확인.
- PDF 버튼 실행 후 앱의 저장 완료 안내 확인. 다운로드 파일의 로컬 위치를 확인하지 못해 PDF 페이지 렌더링 검수는 완료하지 못함.

## 자동 검증

- 리포트 관련 집중 테스트: 37개 통과.
- 시장 신호·실거래·리포트 생성·저장·프런트엔드를 포함한 범위: 237개 통과, 11개 실패.
- 실패 11개는 수정 전 HEAD에서도 같은 테스트가 실패함을 별도로 재현했다. 전체 테스트가 통과한 상태는 아니다.
- JavaScript 구문 검사, Python 구문 검사, git diff 공백 검사 수행.

새 회귀 검증에는 서로 다른 면적 혼입, 취소·미래 거래, 거래 부족, 오래된 거래, 6개월 확대, 홀수·짝수 중앙값, 자료 누락과 거래 감소에 따른 결론, 자금 독립성, 동일 가격 자금 계산 연결, 비교 단지의 지역·면적·중복 식별, 빈 상태·오류 상태, HTML 이스케이프, 카드와 리포트의 건수 일치가 포함된다.

## 남아 있는 범위

- 실제 매물 호가·내부 상태·매도 소요 기간을 확인한 감정평가가 아니다.
- 등급과 표본 기준은 제품 규칙이며 수익률 예측이나 매수 성과가 검증된 모형은 아니다.
- 비교 단지는 조회된 데이터 범위 안에서 선정한다. 지역의 모든 매물을 조사한 결과는 아니다.
- 이번 반영은 로컬 main이며 운영 배포는 하지 않았다.
- 실행 중 학교 자료 캐시가 자동 갱신되었으나 리포트 코드 변경 커밋에는 포함하지 않는다.
