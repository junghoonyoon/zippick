# 용적률·건폐율을 이용한 재건축 여건

리포트의 기존 **단지 변화** 위치에서 현재 건축 규모와 확인된 건축 기준을 비교한다.
현재 거주 조건, 가격 판단, 시장 신호, 종합점수와 공식 추진 단계 별점은 바꾸지 않는다.

## 진행 단계와 사업성에 대한 결론

리포트의 `단지 변화` 제목은 공식 진행 단계와 건축 조건의 판단을 함께 말한다.
예: **재건축은 아직 초기예요. 계획 기준으로는 사업성에 유리한 건축 조건이에요.**
수치만 나열하던 화면을 보완한 것이다. 사업성을 금액으로 계산한 결과는 아니다.

- `reconstructionConditions.feasibility` 한 곳에서 판단한다. 목록·상세·리포트·갱신 API는
  이 결과를 재사용한다. 기존 별점은 진행 단계만 나타내며 수익성 점수로 바꾸지 않는다.
- 단지 전체 범위가 검증된 기준을 우선한다. 그런 기준이 없으면 주소·단지명이 일치한
  공식 재건축 계획을 보고, 계획도 없으면 대표 지번의 조례 기준을 조건부로 참고한다.
- 현재 용적률이 비교 기준보다 낮으면 더 지을 여지를 검토할 수 있는 유리한 요소로 본다.
  차이가 비교 기준의 10% 이내면 여지가 작다고 설명하고, 현재 값이 기준 이상이면
  그 기준 아래에서 규모를 늘리는 데 불리한 조건으로 본다. 기존 설명 기준을 재사용한
  것으로 법적 자격·사업 수익률·성공 확률을 정하는 문턱은 아니다.
- 정비사업 범위가 단지 전체 땅과 같은지 확인되지 않았으면 **계획 기준의 방향**만 말한다.
  면적 증가량·일반분양 물량은 계산하지 않는다. 대표 지번 조례는 제목에도
  `조례 기준이 적용된다면`을 붙여 단지 전체 적용이 미확인임을 밝힌다.
- 건폐율은 현재 배치를 설명하는 보조 자료다. 낮은 건폐율이나 오래된 연식만으로
  사업성이 좋다고 판정하지 않는다. 빈 값·0·연결 실패도 좋음이나 나쁨으로 바꾸지 않는다.
- 공사비·일반분양 수입·공공기여 비용은 아직 연결하지 않아 실제 수익성과 분담금은
  별도로 미판단 상태다. 계획 총세대수에서 기존 세대수를 뺀 값을 일반분양으로 쓰지 않는다.
  [서울시 정비사업 정보몽땅 사업비·분담금 안내](https://cleanup.seoul.go.kr/assc/bbs-use/lscrWctList.do?cafeId=200900000045h80)도
  수입·지출·분담금이 사업 기간, 계약, 정비·건축 계획 변경에 따라 달라진다고 설명한다.
- 최신 자료 조회 실패 시 이전 수치는 보존하되 새로운 긍정·부정 결론은 보류한다.
  리모델링·준공·취소 사업에 재건축 사업성 결론을 붙이지 않는다.

2026-11-11 원본 확인 사례: 강남구 일원동 734 상록수아파트의 현재 용적률은
109.16%, 건폐율은 23.73%, 총괄표제부 세대수는 740이다. 서울시 계획 용적률은
249.99%, 계획 세대수는 1,126이다. 용적률을 높이는 계획을 건축 조건의 유리한
방향으로 설명하며, 대장 대지 61,530㎡와 사업 범위 63,257㎡는 합치지 않는다.
기존 공식 단계 자료의 추진위원회 승인(현황 확인 2026-10-20)은 초기 단계로 유지한다.
이는 로컬 리포트 변경이며 운영 서비스 코드는 아직 배포하지 않았다.

이번 변경 검증: 관련 검사 252개 통과. 마지막 화면 문구 수정 뒤 영향받는 36개를 다시
통과했다. 격리 자료 검사와 별도로 운영 공용 원본의 로컬 연결이 `ready`인 것을 확인했다.
상록수의 갱신 API·두 면적의 리포트 API·입지 점수 API에서 같은 사업성 조건 결과를
확인했고, 상록수 74.54㎡ 리포트를 데스크톱 1280px·모바일 390px에서 열어 결론·근거·
펼침을 확인했다. 월계사슴3단지는 조례 적용을 전제로 한 조건부 판단, 태릉우성은 현재
용적률 누락으로 판단 보류인 것을 실제 API에서 확인했다. 기존 원본을 재사용했으며
이번 결론 수정에서는 새로운 외부 수집을 실행하지 않았다. 전수검사나 운영 배포 검증은 아니다.

## 원본과 단지 연결

- 공식 자료는 건축HUB `getBrRecapTitleInfo`의 총괄표제부다.
- 운영 공용 원본 `building_register_records.json`에 조회 상태와 원문을 함께 보관한다.
  로컬은 `shared_data.cache_path()`로 같은 원본을 자동으로 읽는다.
- 단지 고유번호, 법정동 코드, 지번을 사용한다. 같은 지번에서도 단지명·차수·세대수와
  대장 종류를 확인해 단지 전체 대장을 하나로 정할 수 있어야 값을 사용한다.
- 0·음수·빈 값은 미확인이다. 면적으로 검산한 값과 맞지 않는 비율도 사용하지 않는다.
  동별 표제부의 비율을 평균 내거나 다른 단지·통합 단지 값으로 채우지 않는다.
- 대지면적은 단지 전체 면적이다. 선택한 집 한 채의 대지지분이 아니다.

## 수집과 갱신

리포트를 열 때 `/api/apartment-reconstruction`이 같은 단지의 자료를 조회한다.
운영 primary에서만 빠진 자료를 비동기로 수집한다. 30일 안의 정상 원본은 재사용하고,
동시 수집은 두 건, 대기 중인 단지는 최대 20곳으로 제한한다. 목록 요청은 외부 API를
호출하지 않는다. 로컬 replica는 수집하지 않는다.

운영의 정상 설정으로 다음 명령을 실행할 수 있다.

```sh
PYTHONPATH=pipeline python pipeline/collect_building_register.py --district 노원구 --name 사슴 --dry-run
PYTHONPATH=pipeline python pipeline/collect_building_register.py --district 노원구 --name 사슴
```

`--all --limit N`으로 범위를 제한한 배치 수집도 가능하다. 누락만 이어서 처리하고,
인증·권한·한도 오류가 나면 멈춘다. 성공 응답 수(`success`)와 실제 비율을 쓸 수 있는
단지 수(`usable`, `partial`, `unmatched`)는 다르다. 처리·실패·미처리 수를 함께 확인한다.
수집 파일은 잠금 후 병합하고 검증된 임시 파일로 교체한다. 재조회 실패와 빈 응답은
기존 정상 원본을 지우지 않는다.

브라우저는 수집 상태를 최대 30회 확인한다. 응답 지연은 재조회 버튼으로 끝내며,
옛 응답이 새 단지나 새 리포트를 덮어쓰지 않는다. 같은 단지의 평형들은 비율을 공유한다.

## 판단 기준

30년 이상 단지는 현재 비율과 확인된 건축 기준을 비교할 수 있다. 30년은 설명을 시작하는
집픽의 기준이며 법적 재건축 자격 판정이 아니다. 나이는 기존 연식 평가를 그대로 사용한다.

`data/apartment_reconstruction_context.json`에는 공식 자료를 검증한 경우에만 적용 기준을
등록한다. 단지 고유번호·주소·대지 범위가 모두 같고, 현재 적용되는 한도 또는 확정된
정비계획인지 확인해야 한다. 일반적인 250%·300%를 기본값으로 넣지 않는다.

- 기준 없음: 현재 수치만 표시하고 규모를 늘릴 여지는 판단 보류.
- 현재 한도보다 낮음: 건축 규모를 늘릴 여지를 검토할 수 있다는 설명.
- 한도와 차이가 한도의 10% 이내: 여지가 작다는 설명. 이는 표시용 기준이며 법적·사업성 기준이 아님.
- 확정 정비계획 있음: 현재와 계획 규모를 구분해서 표시.
- 건폐율: 현재 배치를 설명하는 보조 자료. 낮다는 이유로 사업성 가점 없음.

용적률 차이는 `%p`로 표시한다. 일반분양 세대수·수익률·추가분담금으로 환산하지 않는다.
원본 또는 적용 기준이 180일보다 오래되면 긍정적인 요약을 만들지 않는다.

## 2026-11-11 대표 지번 조례와 지구단위계획 확인

  토지이음의 법령·조례 단순 산출은 용적률 250%, 건폐율 50%다.

- 총괄표제부의 현재 용적률 196.53%와 조례 기준의 산술 차이는 53.47%p다.

  지구단위계획은 재건축 정비계획의 승인이나 추진 단계를 뜻하지 않는다.

  [노원구 월계3택지 지구단위계획](https://www.nowon.kr/www/info/dstrcUnitPlan/BD_selectDstrcUnitPlanList.do?q_tap=1014).

  로컬은 공용 원본을 읽는다. PNU의 일반·산지 코드와 건축HUB의 코드가 다르므로
  별도로 만든다. 단지 고유번호·주소·PNU·공식 출처·조회일과 대표 필지의 용도지역
  범위를 확인한 경우에만 조례 참고값을 보여준다. 공식 정비계획은 기존 별도 경로를 쓴다.
- 수작업 확인 대상 1곳, 성공 1곳, 실패 0곳, 미처리 0곳이다. 이 범위는 3단지만이다.
  이 시점에는 다른 단지의 건축 기준·정비계획 자동 수집이 연결되지 않았다. 토지이음의
  전국 지구단위계획·용도지역 공개 파일은 확인했지만, 각 단지의 필지 경계 및
  조례와 결합하고 실제 적용 기준을 검증하는 작업이 남아 있다.
  `import_reconstruction_planning.py`는 직접 검증한 기록을 공용 원본에 병합하는
  수동 도구이며 자동 수집기로 취급하지 않는다.

## 2026-11-11 자동 조회 연결

- 신규 코드 배포 후 리포트를 열면 운영 primary가 단지의 대표 지번을 토지이음에서 조회한다.
  대기 중인 단지는 20곳 이내, 동시 조회는 1건, 요청 간격은 1초 이상이다.
  정상 자료는 30일 동안 재사용한다. 통신 오류는 한 번만 재시도하며, 401·403·429는
  일괄 수집을 멈춘다. 실패하면 마지막 정상 기록을 보존하고 상태와 원인을 남긴다.
- 토지이음의 공개 화면은 **공공누리 출처표시**가 있는 경우에만 사용한다.
  화면에 표시되는 소재지·필지 면적·용도지역·지구단위계획 구역명을 읽고,
  단지 고유번호·법정동·지번 및 PNU와 맞지 않으면 저장하지 않는다.
