## 실제 서울시 수집 확인

- 데이터 기준일: 공식 목록 갱신일 **2026-10-13**. 수집일을 사업 인가일로 바꾸지 않는다.
- 2026-10-15 공식 JSON 내려받기 파일 **830행**, 원본 PK **830개** 확인.
- 공식 Sheet의 총건수 830과 대조했다. 원본 파일 해시는 번들에 저장했다.
- API 명세에 `BASIC_INFO_SEQ`, `BSNS_NAME`, `BSNS_ADDR`, `PROPEL_CD_NM`,
  `PROPEL_DT`, `SUPLY_HSHLD` 등이 있지만 **좌표·경계·보행 경로는 없다**.
- 공식 Open API가 안내하는 HTTP:8088 샘플은 확인했으나 HTTPS:8088 연결은 실패했고
  HTTPS 기본 포트도 시간 초과됐다. 인증키를 HTTP로 보내지 않는다.
- 대안은 공식 화면의 HTTPS JSON 내려받기다. `fetch_seoul()`은 파일을 받고 별도
  Sheet 총건수를 대조한다. 실패 시 최대 3회 재시도, 1·2초 대기, 요청 간 0.3초 간격.
  불완전하면 이전 스냅샷을 유지한다. Python 3.14의 인증서 엄격 검사에서 공식 서버 연결이 거절되면 시스템 curl의 TLS 검증으로 재시도한다. 인증서 검증을 끄거나 HTTP로 전환하지 않는다. 자동 주기 작업은 등록하지 않았다.
- 공식 Sheet 총건수 응답은 엄밀한 JSON이 아니므로 정해진 헤더의 숫자만 파싱한다.
  응답을 JavaScript로 실행하지 않는다.

면적, 시설 개방 일정, 동일 면적 신축과의 비교, 공급·수요를 확보해야 종합점수를 낼 수 있다.

### 생활권 지도 비상업용 표시 (2026-10-15)

사용자가 비상업용 사용을 명시하여 생활권 리포트의 OA-22712 경계를 접속 주소와 관계없이 표시한다. 기존 loopback 미리보기 제한은 제거했다. 원본 도형과 이용조건 `noncommercial_no_derivatives`, `commercialAllowed:false`는 유지하고 `useContext:noncommercial`, `previewOnly:false`로 기록한다. 지도·사업 카드·PDF 거리 표시에 출처와 기준일을 남긴다. 해당 도형의 표시가 수혜 점수의 검증을 대신하지 않는다.

면목선 계획 경유지 명칭은 [동대문구 교통행정과 FAQ](https://www.ddm.go.kr/www/selectBbsNttView.do?bbsNo=278&key=58&nttNo=106839) (2025-02-19, 공공누리 출처표시)에서 확인했다. [서울시 2026-2288 공고](https://www.seoul.go.kr/news/news_notice.do?nttNo=463192&tr_code=snews)의 환경평가 요약문 그림1-8도 대조했으나 원본 지도·선형을 복제하지 않았다. 카카오 Local API의 주민센터 실제 대표점을 사용하며 예정역 출입구와 구분한다. 청량리역은 [국토부 교통계획 자료](https://www.molit.go.kr/2024plan_traffic/news/bodo_2.pdf)의 GTX-B·C 정차 계획과 현재 1호선 역 대표점을 연결한다. 두 자료 모두 예정역의 정확한 출입구나 도보시간 근거로 사용하지 않는다.
