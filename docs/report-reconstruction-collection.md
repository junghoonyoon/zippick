# 리포트 단지변화 자동 수집

리포트를 열면 단지 고유번호·법정동·지번으로 공식 건축 자료를 조회한다.
운영 서버만 건축HUB 총괄표제부와 대표 지번의 토지이음 자료를 수집한다.
정상 원본은 30일 동안 재사용한다. 목록을 표시할 때는 외부 수집을 시작하지 않는다.

로컬의 `/api/apartment-reconstruction`은 같은 운영 API에 공개 단지 식별값만
전달한다. 수집이 끝나면 `shared_data.sync_once()`로 검증한 공용 원본을 읽는다.
원본 동기화는 백그라운드 한 건으로 공유한다. 같은 자료는 다시 내려받지 않고,
긴 동기화가 브라우저 API 응답을 막지 않도록 진행 상태를 바로 돌려준다.
키·예산·소득 등 개인 입력은 전달하지 않는다. 원본은 배포 릴리스 밖의 공용 경로에 보존한다.

리포트는 수집 중에 로딩을 표시하고 완료된 수치와 출처를 같은 구간에 반영한다.
단지변화 구간만 갱신하므로 기존 지도, 항목 순서와 다른 구간의 펼침 상태를 보존한다.
늦은 응답은 새 단지나 새 평형의 결과를 덮어쓰지 않는다.

조회 결과 없음, 단지 일치 실패, 연결 오류와 마지막 정상 자료 사용은 구분한다.
0·빈 비율은 미확인으로 두며, 현재 건축 규모와 추진 단계·사업 수익성을 섞지 않는다.
수집 실패 시 정상 원본을 유지하고 다시 불러오기 버튼으로 재시도한다.

검증에는 격리된 HTTP API의 최초 수집→저장→재사용, 로컬 전달과 원본 동기화,
실패·인증 거절·빈 응답, 59→84→59 전환과 늦은 응답 차단을 포함한다.
배포 뒤에는 이전 미수집 단지와 정상·값 없음 사례의 운영 원본·API·실제 화면을 대조한다.
