# 리포트 단지변화 자동 수집

리포트를 열면 단지 고유번호·법정동·지번으로 공식 건축 자료를 조회한다.
운영 서버만 건축HUB 총괄표제부와 대표 지번의 토지이음 자료를 수집한다.
정상 원본은 30일 동안 재사용한다. 목록을 표시할 때는 외부 수집을 시작하지 않는다.

로컬의 `/api/apartment-reconstruction`은 같은 운영 API에 공개 단지 식별값만
전달한다. 수집이 끝나면 `shared_data.sync_once()`로 검증한 공용 원본을 읽는다.
원본 동기화는 백그라운드 한 건으로 공유한다. 같은 자료는 다시 내려받지 않고,
긴 동기화가 브라우저 API 응답을 막지 않도록 진행 상태를 바로 돌려준다.
키·예산·소득 등 개인 입력은 전달하지 않는다. 원본은 배포 릴리스 밖의 공용 경로에 보존한다.

리포트는 수집 중에 로딩을 표시하고 완료된 수치와 출처를 같은 구간에 반영한다.
단지변화 구간만 갱신하므로 기존 지도, 항목 순서와 다른 구간의 펼침 상태를 보존한다.
늦은 응답은 새 단지나 새 평형의 결과를 덮어쓰지 않는다.

조회 결과 없음, 단지 일치 실패, 연결 오류와 마지막 정상 자료 사용은 구분한다.
0·빈 비율은 미확인으로 두며, 현재 건축 규모와 추진 단계·사업 수익성을 섞지 않는다.
수집 실패 시 정상 원본을 유지하고 다시 불러오기 버튼으로 재시도한다.

검증에는 격리된 HTTP API의 최초 수집→저장→재사용, 로컬 전달과 원본 동기화,
실패·인증 거절·빈 응답, 59→84→59 전환과 늦은 응답 차단을 포함한다.
배포 뒤에는 이전 미수집 단지와 정상·값 없음 사례의 운영 원본·API·실제 화면을 대조한다.

조회 결과가 없으며, 토지 용도지역 정보는 별도로 표시한다. 연결 실패로 분류하지 않는다.

공용 원본 반영까지 확인했다. 로컬 동기화 중 재조회 응답은 표본 0.13~0.17초였고,
전체 화면이나 모든 단지의 속도를 보장하는 검사는 아니다. 실제 자료를 쓴 표본 검수이며
전체 서비스 단지의 전수검사나 전수 수집 결과가 아니다.


## 반복 연결 오류 진단

운영 API 요청과 공용 파일 동기화는 별도 단계다. `sourceConnection.stage`와
`sourceConnection.code`로 HTTPS 인증서 오류, HTTP 실패, SSH 시간 초과를 구분한다.
공용 원본 상태에는 `errorStage`와 `errorReason`을 남긴다. 원래 명령이나 응답의
상세 오류를 공개 API에 넣지 않는다.

Python의 인증서 검증만 실패하면 시스템 HTTPS 클라이언트로 한 번 더 확인한다.
이때도 HTTPS와 인증서·호스트 이름 검증을 유지한다. 응답 크기와 단지 식별값도 검증한다.

공용 파일 동기화가 끊겼어도 운영 API의 원자료·출처·조회일·판단이 로컬 원본으로
계산한 값과 모두 같으면, 해당 단지만 기본 60초 동안 확인된 자료로 재사용한다.
원자료를 다른 곳에 저장하거나 운영 응답의 값으로 로컬 파일을 덮어쓰지 않는다.
모든 화면은 계속 `shared_data.cache_path()`의 같은 파일로 계산한다.
확인 시각은 `sourceVerification.checkedAt`에 남긴다. 전역 SSH 오류는 그대로 표시한다.
단지 식별값이나 원본 버전이 바뀌거나, 확인 시간이 지나거나, API 재확인이 실패하면
이 확인을 해제한다. 하나라도 값이 다르면 기존 원본 동기화와 검증을 거쳐야 한다.

검증에는 격리된 HTTP API의 최초 수집→저장→재사용, 로컬 전달과 원본 동기화,
실패·인증 거절·빈 응답, 59→84→59 전환과 늦은 응답 차단을 포함한다.
배포 뒤에는 이전 미수집 단지와 정상·값 없음 사례의 운영 원본·API·실제 화면을 대조한다.

## SSH 재연결과 시각 자료

SSH 시간 초과·연결 끊김은 최대 한 번 새 연결로 재시도한다. 재시도는 실패한
공유 연결 소켓을 쓰지 않는다. 인증 거절·호스트 키 오류는 재시도하거나 검증을
완화하지 않는다. manifest 조회와 파일 내려받기 모두 같은 규칙을 쓴다.
두 번째 시도도 실패하면 마지막 검증된 세대를 유지하고 다음 자동 주기에 다시 확인한다.

단지 변화는 한 문장 결론 아래에 현재 용적률을 땅 넓이 단위로, 건폐율을
전체 땅에서 건물이 차지하는 막대로 보여준다. 비교 기준을 확인하지 못한 값은
0이나 남은 건축 여지로 바꾸지 않는다. 기준이 있으면 같은 눈금의 두 막대로
비교하며 부지 범위가 다를 수 있는 한계를 밝힌다. 수치·별점·공통 점수는 바꾸지 않는다.

2026-11-13 배포 전 검증: 관련 158개 검사 통과. 추가 공통 판단·문구 검사에서
125개가 통과했고, 학교 거리·자금 제목의 기존 문구 검사 2개는 실패했다.
수정 전 origin/main HTML에서도 같은 실패를 재현했으며 이번 범위에서 변경하지 않았다.
실제 휘경해모로프레스티지 59.8㎡와 종로센트레빌 59㎡ 요청의 로컬·운영 건축
수치가 일치했다. 새 코드로 운영 원본 7,396개 파일(실거래 7,386개)의 동기화를
연속 두 번 확인했다. 연결은 이번 코드 변경 전에 회복된 상태였으며, 모든 네트워크
장애의 재발을 막았다는 의미는 아니다.
